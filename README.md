# Мой бюджет

PWA для личного бюджета на русском: баланс месяца, доходы и расходы по категориям, лимиты, цель накоплений и калькуляторы. Данные только на устройстве (`localStorage`). Без бэкенда и без внешних CDN.

**Демо:** https://lueissa.github.io/moy-budget/

## Как открыть локально

```bash
cd finance-app
python3 -m http.server 8080
```

Откройте [http://localhost:8080/](http://localhost:8080/). Либо откройте `index.html` напрямую (PWA-установка удобнее через `http://`).

## Экраны

| Экран | Что внутри |
|-------|------------|
| **Главная** | Крупный баланс месяца, доходы/расходы, быстрые «+ Доход / − Расход», превью цели и лимитов, недавние операции |
| **Операции** | Полный список с фильтром: Все / Доходы / Расходы |
| **Цели** | Цель накоплений с кольцом прогресса и «Отложить» |
| **Ещё** | Калькуляторы (процент; сколько в месяц до цели), лимиты категорий, сброс данных |

Дополнительно: переключение месяца, онбординг при первом запуске, bottom tab bar, bottom sheets для форм.

## Возможности

- Баланс месяца (доходы − расходы), формат ₽ / `ru-RU`
- Категории: Еда, Транспорт, Жильё, Связь, Здоровье, Развлечения, Другое
- Бюджет-лимиты по категориям с прогрессом (зелёный → янтарный → красный)
- Цель накоплений: прогресс, пополнение, редактирование
- Калькуляторы и сброс данных
- PWA: `manifest.json` + service worker
