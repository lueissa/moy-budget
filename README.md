# Мой бюджет

Персональный финансовый калькулятор на русском языке: месячный бюджет, категории расходов, цель накоплений и быстрые калькуляторы. Данные хранятся только на устройстве (`localStorage`). Готов к «Добавить на главный экран» как PWA.

## Как открыть локально

1. Откройте папку `finance-app` в проводнике или терминале.
2. Запустите любой статический сервер в этой папке (нужен для service worker; для проверки UI достаточно и двойного клика по `index.html`):

```bash
cd finance-app
python3 -m http.server 8080
```

3. В браузере откройте: [http://localhost:8080/](http://localhost:8080/)

Либо откройте файл напрямую: `finance-app/index.html` (офлайн-функции бюджета работают и так; установка PWA удобнее через `http://localhost`).

**Сброс:** кнопка «Сбросить данные» в шапке очищает все записи на этом устройстве.

## Что умеет приложение

- **Бюджет:** список доходов и расходов; категории — Еда, Транспорт, Жильё, Связь, Здоровье, Развлечения, Другое.
- **Баланс:** доходы − расходы, формат рублей (₽).
- **Цель накоплений:** название, сумма цели, уже накоплено, прогресс-бар, пополнение.
- **Калькуляторы:** процент от суммы; сколько откладывать в месяц до цели за N месяцев.
- **Офлайн:** ядро кэшируется service worker’ом; данные — в `localStorage`.

## Дальше: Google Play / App Store (Capacitor)

Краткий план упаковки в нативные магазины:

1. Установить [Node.js](https://nodejs.org/) и создать оболочку Capacitor:

```bash
npm init -y
npm install @capacitor/core @capacitor/cli
npx cap init "Мой бюджет" com.liza.finance --web-dir .
npm install @capacitor/android @capacitor/ios
npx cap add android
npx cap add ios
npx cap sync
```

2. Собрать Android: Android Studio → `npx cap open android` → Build / Generate Signed Bundle.
3. iOS: macOS + Xcode → `npx cap open ios` → Archive → App Store Connect.
4. Перед релизом: иконки/сплэш (1024×1024), политика конфиденциальности (данные локальные), тестовые аккаунты, скриншоты магазинов.
5. Опционально: бэкап в облако, биометрия, подписки — уже как отдельный продуктовый этап.
