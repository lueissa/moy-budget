# Мой бюджет

PWA для личного бюджета на русском: баланс месяца, доходы и расходы по категориям, лимиты, цели накоплений и калькуляторы. Ежедневные инсайты и стрик помогают возвращаться каждый день. Данные только на устройстве (`localStorage`). Без бэкенда и без внешних CDN.

**Монетизация:** бесплатно с рекламой-заглушкой (AdMob позже через Capacitor); покупка «Убрать рекламу». Награда за просмотр: 2-я цель или снятие дневного лимита операций.

**Демо:** https://lueissa.github.io/moy-budget/

## Как открыть локально

```bash
cd finance-app
python3 -m http.server 8080
```

Откройте [http://localhost:8080/](http://localhost:8080/). Либо откройте `index.html` напрямую (PWA-установка удобнее через `http://`).

## Экраны

| Экран | Что внутри |
|-------|------------|
| **Главная** | Баланс + «можно потратить сегодня», инсайт дня, стрик 🔥, быстрые чипы расходов, цель и лимиты |
| **Операции** | Полный список с фильтром: Все / Доходы / Расходы |
| **Цели** | Цели накоплений (1 бесплатно, 2-я через рекламу) с прогрессом и «Отложить» |
| **Ещё** | Поддержка (реклама / без рекламы), калькуляторы, лимиты категорий, сброс данных |

Дополнительно: переключение месяца, онбординг «вау за 30 секунд», bottom tab bar, bottom sheets для форм.

## Возможности

- Баланс месяца и дневной лимит («ещё можно потратить сегодня»)
- Инсайт дня одной строкой и стрик дней 🔥
- Быстрые чипы: кофе / транспорт / продукты
- Онбординг за 30 сек + демо-данные одним тапом
- Праздники 25/50/100% цели и первой операции
- Баланс месяца (доходы − расходы), формат ₽ / `ru-RU`
- Категории: Еда, Транспорт, Жильё, Связь, Здоровье, Развлечения, Другое
- Бюджет-лимиты по категориям с прогрессом (зелёный → янтарный → красный)
- Цель накоплений: прогресс, пополнение, редактирование
- Калькуляторы и сброс данных
- Freemium: баннер и rewarded-заглушка; план free/pro в `localStorage`
- PWA: `manifest.json` + service worker
