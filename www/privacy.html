Политика конфиденциальности

Приложение «Мой бюджет» · обновлено: 26 сентября 2026 · v2

Коротко: «Мой бюджет» — приложение для личного учёта доходов и расходов. Это не финансовая услуга и не банк. Правообладатель не собирает и не продаёт персональные данные: записи хранятся только на вашем устройстве. Аккаунта и собственного сервера нет. В магазинных сборках возможна реклама (AdMob) — с ограничениями для младшей аудитории (см. п. 3 и 7).

Важно: «Мой бюджет» — инструмент личного учёта. Это не банковский продукт, не платёжный сервис и не финансовая услуга. Приложение не принимает деньги на хранение, не открывает счета и не даёт инвестиционных или кредитных рекомендаций.

1. Кто мы

Приложение «Мой бюджет» (идентификатор пакета com.moybudget.app) предназначено для личного учёта доходов, расходов и целей накоплений. Правообладатель приложения — независимый разработчик (публикатор в RuStore / Google Play).

Этот документ — шаблон для инди-разработчика и не является юридической консультацией. Перед публикацией при необходимости уточните формулировки у юриста.

2. Какие данные обрабатываются

  • Финансовые записи (суммы, категории, цели, настройки) — только локально на устройстве (localStorage / хранилище приложения). На серверы разработчика они не отправляются: собственного бэкенда нет.
  • Аккаунт / регистрация — не требуются и не предоставляются.
  • Платёжные данные карты — разработчик их не получает. Покупка «Убрать рекламу» (единоразово, 89 ₽) обрабатывается магазином приложений (RuStore / Google Play).

3. Реклама и рекламный идентификатор

В веб-демо (GitHub Pages) реклама — локальная заглушка: сторонние рекламные SDK не подключаются, данные рекламным сетям не передаются.

В релизах для RuStore / Google Play могут подключаться рекламные сети (в том числе Google AdMob). Ориентир политики приложения (РФ): граница 14 лет.

  • для пользователей младше 14 лет: только неперсонализированная реклама / режим child-directed treatment либо реклама не показывается до достижения 14 лет;
  • персонализированная реклама AdMob — только для пользователей 14 лет и старше;
  • при показе рекламы может использоваться рекламный идентификатор устройства (Advertising ID / AAID) и технические данные, необходимые сети; обработка — по политике Google / сети и настройкам ОС;
  • правообладатель не продаёт персональные данные и не обещает доход / «пассивный заработок» от рекламы.

4. Покупки в приложении

Опция «Убрать рекламу» — единоразовый In-App Purchase (ориентир цены: 89 ₽ навсегда). Факт покупки подтверждает магазин; данные вашей банковской карты разработчику недоступны. Подробнее — в публичной оферте.

5. Передача и продажа данных

Данные пользователей не продаются. Передача третьим лицам возможна только в объёме, необходимом рекламным SDK (см. п. 3), либо по требованию закона.

6. Права пользователя: хранение и удаление

Все записи бюджета находятся на вашем устройстве. Вы можете:

  • удалить данные функцией «Сброс данных» в разделе «Ещё» приложения;
  • удалить само приложение — локальное хранилище будет очищено средствами ОС.

Резервных копий на серверах разработчика нет: восстановить удалённые локальные данные через поддержку нельзя.

7. Возрастная аудитория

Приложение — инструмент личного учёта для широкой аудитории, в том числе доступно пользователям младше 14 лет. Рекомендуемый возрастной рейтинг в магазинах: 6+ или 0+ (аудитория включает младше 14; не 16+ / 18+). Приложение не позиционируется как «детский продукт» или приложение «для малышей», особенно при наличии рекламы.

Данные учёта — только локально; аккаунта нет. При рекламе в релизе — см. п. 3: для младше 14 — неперсонализированная / child-directed либо без показа рекламы; персонализированная — только 14+. Покупка «Убрать рекламу» (89 ₽) для пользователей младше 14 лет — с согласия родителя или законного представителя по правилам магазина.

8. Изменения

Политика может быть обновлена при подключении рекламы, покупок или изменении требований магазинов. Актуальная версия всегда доступна по этому адресу. Дата и версия указаны в шапке документа.
