## RuStore

- [ ] **Возрастной рейтинг: 0+ или 6+** (максимум 12+). **Не выбирать 16+ / 18+** — приложение подходит для младше 14 лет: данные только локально, аккаунта нет
- [ ] Скриншоты **без чужих брендов** банков, карт, логотипов платёжных систем (иконки/UI приложения — свои)
- [ ] Описание правдивое: учёт на устройстве, freemium, цена «Убрать рекламу» **89 ₽** (не завышать и не обещать лишнего)
- [ ] Не писать «банк», «вклад», «гарантированный доход», «инвестиции с доходностью»
- [ ] Если включаете IAP: для приёма платежей от имени физлица RuStore **обычно требует самозанятость (НПД)** и привязку выплат — см. `offer.html` и кабинет RuStore
- [ ] Покупка 89 ₽ несовершеннолетними — с согласия родителя / по правилам магазина
- [ ] Без самозанятости можно сначала выложить бесплатную версию (реклама-заглушка / без IAP), покупку включить позже

## Google Play

- [ ] Разовый взнос разработчика **~$25**; из РФ часто нужна **зарубежная карта** (или иной доступный вам способ). Пароли/CVV никому не отправлять
- [ ] Privacy policy URL указан
- [ ] **Целевая аудитория / возрастной рейтинг:** указывайте честно аудиторию включая младше 14 (IARC / целевые группы Play). **Не 16+ / 18+** — контент подходит для 0+ / младших возрастов
- [ ] **Data safety** — честно:
  - Пока **без AdMob** и без своего бэкенда: данные приложения (бюджет) только на устройстве → в форме обычно **Data collected? No** (уточняйте актуальные формулировки Play Console)
  - **После подключения AdMob**: Data collected? **Yes** → Advertising ID / данные для рекламы; purpose: Advertising; не продаёте данные
- [ ] В описании, если есть реклама: честно указать наличие ads / возможность IAP «Убрать рекламу»
- [ ] IAP managed product «Убрать рекламу» = **89 ₽**, one-time; для несовершеннолетних — согласие родителя по правилам Play
- [ ] Контентный рейтинг (IARC) пройден → ожидаемо низкий рейтинг (не 16+/18+)

---

## Реклама (AdMob)

- [ ] В описании магазина — disclosure о рекламе (когда реально подключена)
- [ ] Политика privacy уже описывает Advertising ID (готово в `privacy.html`)
- [ ] Data safety обновлён **в тот же релиз**, когда AdMob попадает в сборку
- [ ] Для аудитории **младше 14**: только **неперсонализированная** реклама / **child-directed treatment** в AdMob — **либо** реклама только для 13+
- [ ] Не обещать «гарантированный доход от рекламы» в карточке или маркетинге
