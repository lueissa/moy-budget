# Юридический чеклист перед модерацией (RuStore / Google Play)

Честный минимум для инди. **Не юридическая консультация** — при сомнениях уточните у юриста / бухгалтера.

Приоритет: **moderation-safe / regulator-safe** — формулировки, из‑за которых реже «докапываются».

| Документ | URL |
|----------|-----|
| Политика конфиденциальности | https://lueissa.github.io/moy-budget/privacy.html |
| Пользовательское соглашение | https://lueissa.github.io/moy-budget/terms.html |
| Оферта «Убрать рекламу» 89 ₽ | https://lueissa.github.io/moy-budget/offer.html |

Пакет: `com.moybudget.app` · В текстах: «независимый разработчик» / «правообладатель приложения» (без личных имён в политике).

**Возраст:** в RuStore/Play рекомендуем рейтинг **6+** (доступно младше 14). Не 16+/18+. При наличии рекламы **не** позиционировать как «приложение для малышей» / «детский продукт».

**Формулировка продукта:** «приложение для личного учёта доходов и расходов» — не финансовая услуга, не банк, не кредит, не инвестиции.

---

## Чтобы не отклонили (топ ошибок модерации)

- [ ] В описании / скринах / keywords **нет**: банк, вклад, кредит, инвестиции, «гарантированный доход», «пассивный заработок», обещаний дохода от рекламы
- [ ] Везде ясно: **личный учёт** на устройстве, не финusлуга и не платёжный сервис
- [ ] Возраст **6+** (допустимо 0+/до 12+); **не** 16+/18+; при рекламе — не «детское приложение для малышей»
- [ ] Privacy URL открывается; пакет в политике = `com.moybudget.app`
- [ ] Data safety Play **совпадает с билдом**: без AdMob → данные не собираются; с AdMob → Advertising ID + purpose ads
- [ ] Если AdMob и аудитория младше 14 → только **неперсонализированная** / child-directed **либо** реклама не показывается до 13
- [ ] IAP 89 ₽ — только через магазин; в RuStore IAP — **после самозанятости (НПД)**; до этого можно выложить **без** платных покупок
- [ ] Скрины/иконки **без** чужих банковских trademark и чужих логотипов
- [ ] Цена везде **89 ₽**, не 149; нет вводящих в заблуждение обещаний
- [ ] Нет следов чужих package id / чужих имён разработчика в сторе и legal-страницах
- [ ] Email в privacy/terms/offer заменён на ваш перед публикацией

## RuStore

- [ ] Возрастной рейтинг: рекомендовать **6+** (доступно младше 14; максимум 12+). **Не 16+/18+**
- [ ] Не позиционировать карточку как «детский продукт для малышей», если планируется реклама
- [ ] Скриншоты без чужих брендов банков / платёжных систем
- [ ] Описание: личный учёт, freemium, «Убрать рекламу» **89 ₽** — без банковских и инвестиционных обещаний
- [ ] IAP: только после **самозанятости (НПД)** и настройки выплат; иначе сначала релиз **без** платных покупок
- [ ] Покупка несовершеннолетними — согласие родителя по правилам магазина

---

## Google Play

- [ ] Взнос ~$25; из РФ часто нужна зарубежная карта. Пароли/CVV никому не отправлять
- [ ] Privacy URL указан
- [ ] Целевая аудитория / IARC: честно, включая младше 14 при необходимости; рейтинг низкий (**6+**-уровень), **не** 16+/18+
- [ ] **Data safety**
  - Пока **без AdMob**: Data collected? **No** (бюджет только на устройстве)
  - **После AdMob**: Data collected? **Yes** → Advertising ID; purpose: Advertising; не продаёте данные
- [ ] Disclosure о рекламе в описании — когда реклама реально в сборке
- [ ] IAP «Убрать рекламу» = **89 ₽**, one-time, только через Play Billing

---

## Реклама (AdMob)

- [ ] В privacy уже описаны Advertising ID и режим для младшей аудитории
- [ ] Data safety обновлён **в том же релизе**, что и SDK
- [ ] Для младше 14: **неперсонализированная** / child-directed **либо** без показа до 13
- [ ] Никогда не обещать доход / «пассивный заработок» от рекламы

---

## Монетизация и налоги

- [ ] Оплата IAP только через RuStore / Google Play
- [ ] RuStore IAP → самозанятость (НПД); до этого — публикация без IAP допустима
- [ ] Налоги / статус — зона ответственности разработчика
